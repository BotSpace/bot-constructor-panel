# Atamalar lug'ati

Bot Constructor Panel'da ishlatiladigan atamalar.

## A

### Action (Harakat)
Bot bajaradigan amal — xabar yuborish, tahrirlash, o'chirish va h.k.

### API (Application Programming Interface)
Dasturlar orasida ma'lumot almashish uchun interfeys.

## B

### Bot
Telegram'da avtomatik xabarlar yuboruvchi va qabul qiluvchi dastur.

### Bot Token
BotFather tomonidan berilgan maxfiy kalit. Bot'ni boshqarish uchun ishlatiladi.

## C

### Callback Data
Inline tugma bosilganda yuboriladigan ma'lumot (64 bayt).

### Callback Query
Foydalanuvchi inline tugmani bosganda Telegram serverga yuboriladigan so'rov.

### Canvas
Bot oqimini quradigan vizual maydon.

### Chat ID
Telegram chat'ning unikal identifikatori (raqam).

### Collection (Kolleksiya)
Bot ichidagi ma'lumotlar to'plami (ma'lumotlar bazasi).

### Custom Code
Python tilida yoziladigan maxsus kod bloki.

## D

### Drag and Drop
Sichqoncha bilan sudrab olib tashlash usuli.

## E

### Edge
Ikki node orasidagi ulanish (chiziq).

## F

### Flow (Oqim)
Triggerdan boshlab ketma-ket bajariladigan node'lar zanjiri.

### Form
Foydalanuvchidan ketma-ket ma'lumot to'plovchi node.

## G

### Global
Har qanday holatda (state'da) ishlaydigan trigger.

## H

### Handle
Node'ning ulanish nuqtasi (Target yoki Source).

### HTTP Request
Tashqi serverlarga yuborilgan so'rov.

## I

### Inline Keyboard
Xabar ichida joylashgan tugmalar.

### If Node
Shartni tekshirib ikki yo'lga ajratuvchi node.

## J

### JSON
Ma'lumotlarni saqlash va almashish formati.

## K

### Keyboard
Telegram'dagi tugmalar (Inline yoki Reply).

## L

### Loop
Takrorlanadigan amallar ketma-ketligi.

## M

### Message Trigger
Xabar kelganda ishlaydigan trigger.

## N

### Node
Bot oqimidagi bitta blok (trigger, harakat, mantiq).

## O

### OAuth
Uchinchi tomon orqali kirish tizimi.

## P

### Parse Mode
Matn formatlash rejimi (HTML, Markdown).

### Properties Panel
Tanlangan node xususiyatlarini ko'rsatuvchi o'ng panel.

## R

### Reply Keyboard
Klaviatura o'rnida ko'rinadigan tugmalar.

## S

### Session
Foydalanuvchi bilan bot o'rtasidagi muloqot davri.

### Source Handle
Node'ning chiqish nuqtasi (pastda).

### State (Holat)
Foydalanuvchining joriy bosqichi yoki holati.

## T

### Target Handle
Node'ning kirish nuqtasi (tepada).

### Trigger
Bot oqimini boshlovchi hodisa.

### Token
Bot'ni boshqarish uchun maxfiy kalit.

## U

### User ID
Telegram foydalanuvchisining unikal identifikatori.

## V

### Variable (O'zgaruvchi)
Ma'lumotni vaqtincha saqlovchi nomlangan qiymat.

## W

### Webhook
Server tomonidan yuborilgan avtomatik xabar.

## Z

### Zustand
Dastur holatini boshqarish kutubxonasi.
