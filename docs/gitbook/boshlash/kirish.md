# Kirish

## Bot Constructor Panel nima?

**Bot Constructor Panel** — bu Telegram botlarini kodlamasdan vizual tarzda yaratish imkonini beruvchi platforma. Siz tayyor bloklarni (node'larni) sudrab olib joylashtirib, ular orasida bog'lanishlar yaratib, bot logikasini qurasiz.

## Nima uchun Bot Constructor?

### ✅ Kodlash shart emas
Dasturlashni bilmasangiz ham professional darajadagi bot yaratishingiz mumkin. Barcha amallar vizual tarzda bajariladi.

### ✅ Tez va oson
Bir necha daqiqada ishlaydigan bot yarating. Murakkab logika ham bloklarni ulash orqali quriladi.

### ✅ Kuchli imkoniyatlar
Oddiy javoblardan tashqari:
- Ma'lumotlar bazasi (kolleksiyalar)
- Shartli mantiq (if/else)
- Tsikllar va kechikishlar
- Tashqi API'lar bilan integratsiya
- Python kod yozish imkoniyati

### ✅ Real-time preview
Har bir o'zgarishni saqlagan zahoti botingizda sinab ko'ring.

## Qanday ishlaydi?

1. **Node'lar** — har bir blok biror vazifani bajaradi
2. **Edge'lar** — bloklar orasidagi ulanishlar
3. **Oqim (Flow)** — foydalanuvchi xabar yuborganda qaysi bloklar ketma-ket ishga tushishi

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   /start    │────▶│   Salom!    │────▶│  Menu      │
│  (Trigger)  │     │   (Matn)    │     │ (Tugmalar) │
└─────────────┘     └─────────────┘     └─────────────┘
```
