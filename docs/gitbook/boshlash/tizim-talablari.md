|---------|-----------------|-----------------|
| Google Chrome | 90+ | ✅ Eng yaxshi |
| Mozilla Firefox | 88+ | ✅ Yaxshi |
| Microsoft Edge | 90+ | ✅ Yaxshi |
| Safari | 14+ | ⚠️ Ishlaydi |

{% hint style="warning" %}
**Internet Explorer** qo'llab-quvvatlanmaydi.
{% endhint %}

## Ekran o'lchami

| Qurilma | Qo'llab-quvvatlash |
|---------|-------------------|
| Desktop (1280px+) | ✅ To'liq funksionallik |
| Planshet (768px-1279px) | ⚠️ Asosiy funksiyalar |
| Mobil (768px dan kichik) | ❌ Qo'llab-quvvatlanmaydi |

{% hint style="info" %}
Vizual editor faqat **desktop** va **planshet** qurilmalarda ishlaydi. Mobil qurilmalarda faqat ko'rish mumkin.
{% endhint %}

## Internet tezligi

- **Minimal**: 1 Mbps
- **Tavsiya etilgan**: 5+ Mbps

Sekin internetda katta oqimlar (flow) yuklanishi sekin bo'lishi mumkin.

## Telegram bot tokeni

Bot yaratish uchun sizga **Telegram Bot Token** kerak bo'ladi:

### Token olish

1. Telegram'da [@BotFather](https://t.me/BotFather) ni oching
2. `/newbot` buyrug'ini yuboring
3. Bot uchun nom bering (masalan: "Mening botim")
4. Bot uchun username bering (masalan: `mening_botim_bot`)
5. BotFather sizga **token** beradi

### Token formati

Token quyidagi formatda bo'ladi:
```
123456789:ABCdefGHIjklMNOpqrsTUVwxyz
```

{% hint style="danger" %}
**Token sirli!** Uni hech kimga bermang. Token orqali botingizni boshqarish mumkin.
{% endhint %}
