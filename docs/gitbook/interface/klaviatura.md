# Klaviatura qisqartmalari

Bot Constructor Panel'da ish tezligini oshirish uchun klaviatura qisqartmalaridan foydalaning.

## Umumiy

| Qisqartma | Mac | Vazifa |
|-----------|-----|--------|
| `Ctrl+S` | `Cmd+S` | Saqlash |
| `Ctrl+Z` | `Cmd+Z` | Bekor qilish (Undo) |
| `Ctrl+Shift+Z` | `Cmd+Shift+Z` | Qaytarish (Redo) |
| `Ctrl+Y` | `Cmd+Y` | Qaytarish (Redo) |
| `Ctrl+A` | `Cmd+A` | Hammasini tanlash |
| `Escape` | `Escape` | Tanlashni bekor qilish |

## O'z qisqartmalarini yaratish

{% hint style="info" %}
Hozircha o'z qisqartmalarini yaratish imkoniyati mavjud emas. Kelgusida qo'shilishi kutilmoqda.
{% endhint %}

## Maslahatlar

### Tez ishlash uchun

1. **`Ctrl+K`** bilan node'larni qidiring — panelni aylanmasdan
2. **`Ctrl+D`** bilan node'larni tez nusxalang
3. **`Space + Drag`** bilan canvas'ni qulay suring
4. **`Ctrl+1`** bilan butun oqimni ko'ring

### Xatolarni oldini olish

1. Tez-tez **`Ctrl+S`** bosing — avtosaqlash ham bor, lekin ishonchli
2. **`Ctrl+Z`** bilan xatoni tez tuzating
3. **`Escape`** bilan noto'g'ri tanlashni bekor qiling
